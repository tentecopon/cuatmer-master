# 顧客カードボックス

電話対応中でもすぐ確認できる、顧客情報・納入装置・他社装置を管理するシンプルなWebツールです。
サーバー不要、単一のHTMLファイルのみで動作します。

## 主な機能

- 顧客カードの作成・編集・削除（会社名、担当者、連絡先、住所、タグ、メモ）
- 納入装置一覧（自社）と他社装置欄を分けて登録・管理
- 装置ごとにデータ格納先のURLを登録可能
- 会社名の頭文字によるタブ絞り込み、フリーワード検索
- 📞 電話対応モード：大きな文字で読みやすい専用の検索・参照画面
- 最終更新日時の自動記録
- バックアップ（JSON書き出し）／復元（JSON読み込み）機能

## データの保存について

このツールはブラウザの `localStorage` にデータを保存します。**保存先はブラウザ・端末ごとに独立しており、他の端末や他のブラウザとは共有されません。**

- 同じ端末・同じブラウザであれば、次回アクセス時もデータは残ります
- ブラウザのキャッシュ／サイトデータを消去すると、保存したデータも失われます
- 複数端末で使う場合や、バックアップを取りたい場合は、画面上部の「バックアップ / 復元」機能を使ってJSONファイルを書き出し・読み込みしてください

## GitHub Pagesで公開する方法

1. このリポジトリの **Settings** → **Pages** を開く
2. "Build and deployment" の Source で **Deploy from a branch** を選択
3. Branch を `main`（または公開したいブランチ）、フォルダを `/root` に設定して **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能になります

## ローカルで動かす方法

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存パッケージのインストールは不要です。
